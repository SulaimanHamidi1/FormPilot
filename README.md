# job_filler

A lightweight Chrome extension (Manifest V3) that fills job application forms
from a profile you save once. Everything stays on your device in
`chrome.storage.local`; nothing is sent to any server.

## Install (load unpacked)

1. Clone this repo.
2. Open `chrome://extensions` in Chrome (or any Chromium browser).
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick the repo folder (the one containing
   `manifest.json`).
5. The settings page opens on first install. Pin the extension from the puzzle
   icon in the toolbar.

After pulling new changes, press the reload icon on the extension's card in
`chrome://extensions`.

## Use

- Open a job application and click the toolbar icon, then **Fill this page**,
  or press **Alt+Shift+J**. You can change the shortcut at
  `chrome://extensions/shortcuts`.
- The extension never submits a form. Review everything before you submit.

## Project layout

```
manifest.json          MV3 manifest
src/background/sw.js   service worker: injects content scripts on demand
src/content/           field detection, matching, filling, on-page prompt
src/popup/             toolbar popup
src/options/           profile editor, onboarding, resume import
src/shared/            profile schema, storage helpers, text utilities
icons/                 extension icons (generated by tools/make-icons.js)
```

## Permissions

- `storage`: saves your profile locally.
- `activeTab` + `scripting`: injects the filler into the current tab only when
  you click **Fill** or press the shortcut.
- `<all_urls>` (optional, off by default): lets the filler reach application
  forms embedded in iframes from another domain.
